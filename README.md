# Hi, I'm Uğur 👋

I'm a Software Engineer at **Garanti BBVA Technology**, working on secure payment systems and event-driven applications with **Java, Spring Boot, and Apache Kafka**.

I enjoy untangling complex problems, improving large codebases, and building shared libraries that make other teams' work easier. My work spans payment integrations, application security, concurrency, and platform modernization. I also serve as a division-level Kafka subject matter expert and contribute to an AI-assisted software security initiative.

I'm interested in making AI a practical part of everyday engineering. I build custom agents and maintain a reusable toolkit with shared memory, MCP integrations, tools, and development rules across IDEs and environments. Alongside this toolkit, I work with our team's Claude-based digital worker and explore context and token optimization.
